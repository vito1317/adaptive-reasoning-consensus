## 二、這次改稿改出來的兩個新問題（優先修）

| cell | γ*（未截斷） |
|---|---|
| κ = −0.6 / +0.6 | −12.09 / +12.11 |
| κ = −0.4 / +0.4 | −8.36 / +9.76 |
| 三個 monotone distortion | +12.115 |

沒有一個接近 38。段落的**論點不受影響**（全都遠超 γ_max = 4，cap 確實在綁，「derived magnitude 沒在做事、sign 才是」成立），但這段的存在意義就是給讀者一個可驗算的數字，而那個數字差了三倍。改成 ±12，或寫成「七個飽和 cell 落在 −8.4 到 +12.1」。

## 三、剩下的 10 條重大問題

**唯一的機械性投稿門檻**

1. **仍然沒有任何 code / data availability statement 或 repo URL。** 你把測試數改成 98 —— 這證明你確實去對過套件了，所以讀者現在拿到一個準確的數字，指向一個他們仍然拿不到的東西。「released」「committed」在 §IV-B、V-C、V-F、VII 反覆出現，Table IV 整張表就是用測試名稱代替論文裡沒寫的證明。這是唯一一條會讓稿子停在編輯桌上而不是審稿人桌上的問題，而它是一行的修法：寫出 repo 與產出 Table IV 的 commit / tag。

**只存在於摘要的四條**（正確措辭在稿子別處都已經有了）

2. 摘要結尾仍是 `all of which the method survived`，沒帶到 Discussion 自己報的 TACT-LF 在 paraphrased wrong-majority cell「mis-signs、飽和在 γ=−2.0、得分 0.000 對 SC floor 0.340」，而且「四個 alarm 都沒響」。你這輪已經用完全相同的精神修掉 oracle 與 CISC anchor，這條是最後一個大缺口。
3. `Two real-trace campaigns … confirm the premise` —— 第一場量到 D̂ = −0.219、z = −1.24，方向是反的。Discussion 已經改對了（「null on saturated benchmarks and positive on competition mathematics」），把那句話搬到摘要即可。
4. 摘要把 p̄ = 1/2 的特例當成一般化簡（`exponent reduces to γ=z√(2+z²)`）。Eq. (15) 自己寫了「At the default p̄ = ½」。加六個字就好。
5. 摘要只點名 CISC-devT 當 killer baseline，沒提 SignGrid-dev。κ=−0.6 那格 `tact_eval.json` 記的是 `{a_only: 0, b_only: 0, p_value: 1.0}` —— 逐位元相同；九格裡 SignGrid 平手五次、領先四次、從未落後。

**方法與論證**

6. **F1/F2 的「significantly below」實作上是硬寫死的 0.02 準確率容差，沒有任何統計檢定。** `experiments/run_tact_eval.py:212-218`：`f2 = any(acc[TACT] < acc[SC] - 0.02)`。0.02 這個數字論文裡完全沒出現，而 F4 能存活整個靠 distortion 格的 0.035 大於這個未公開的 0.02、且只跑一個 seed。預先登錄的 falsification 被當成本文最可移植的貢獻，它的判定規則就必須寫在論文裡。
7. **每個合成 cell 都只有一個 seed（`seed: 0`）、沒有任何離散度。** 這次改稿還把曝險擴大了：新段落現在又把四個 0.012–0.015 的中段差異拿來論證「analytic map 選 magnitude 沒有更好」。400 個配對項目上 0.012 是五題。
8. **`None of these can represent` 仍然把「搜尋範圍的選擇」講成「表達能力的限制」**，而你自己的 SignGrid-dev 就是同一個 c^γ family 放開符號、而且橫跨整個負半軸打到 signed oracle。障礙是超參數格線裡的一個符號位元。你這輪已經對 oracle claim 做過一模一樣的修正。
9. **Bayes-discriminant link 假設 φ 在 item 內常態，但 φ 依 Eq. (2) 是 midrank 的 van der Waerden 分數** —— m_q = 4 時標準化前只有四個值。你處理了尺度問題（用實現的 σ_q，並註明「0.62 at m=4 but 0.95 at m=40」），沒處理分布假設，而這正好落在你當賣點的小預算情境（「m=40 估的指數轉移到 m=8」）。這輪公開了 cap 在飽和處綁住之後，link 唯一還要成立的地方就是小 m。
10. **貢獻清單仍是四條，沒有一條提到真實 trace 或 window 量測。** §V-G–V-I 是 Results 較大的一半，而 window 量測界定的是**整個方法族**、不只 TACT —— 這是全篇最可移植的實證結果。Discussion 已經改對了（「neither substrate … large enough for any method to demonstrate a gain」），但第 1 頁還沒承載這件事。
11. **論文把自己的動機證明近乎為空，卻沒把論證收尾。** 依你自己的量測，整個方法族的天花板是 3–7.5% 的題目，兩場真實實驗也確實回傳 γ=0、與 SC 逐位元相同。稿子仍然以 estimator 開場，從未說明「在這個可作用區間下，為什麼這個方法值得採用」，也沒有改成「以邊界量測為主、TACT 是在其中正確棄權的估計器」。這是結構性的重寫，但**是重新框架，不需要新實驗**。
