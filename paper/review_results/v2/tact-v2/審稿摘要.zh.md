## 二、這輪額外驗的兩件（前八輪都沒查過）

**1. `build_tmlr.py` 的匿名防護 —— 我不只讀，實際觸發它。**

```
current anonymous source  → PASSES
injected 'vito1317'       → caught      injected 'github.com/x'          → caught
injected 'Wei-Chen Ko'    → caught      injected 'Independent Researcher'→ caught
injected '柯瑋宸'          → caught      injected 'service@vito1317.com'  → caught
```

兩處改寫現在用 `re.subn` 加 `if n != 1: raise AssertionError`，所以正則哪天靜默失配會**中斷 build**，而不是把去匿名化的稿子送出去。這個模式對不可逆動作是對的 —— 你自己在註解裡寫了「a leaked submission cannot be recalled」。

兩份 TMLR PDF 都沒有 Author / Title / Subject / Keywords 欄位，只有 `format` / `creator` / `producer` / `creationDate`。乾淨。

## 四、關於「0 條」的意思

這代表九輪提出的每一條都已關閉，並各自對released artifacts、實作程式或渲染後的 PDF 獨立驗證過。

**這不是對審稿結果的預測。** 這篇論文用自己的量測把可作用區間界定在 2.5–7.5%，貢獻夠不夠格是編輯與審稿人的判斷 —— 而現在論文把這件事**明講出來**（C5 + Conclusion 都以量測為主軸），而不是留給審稿人自己發現。這是這輪之後最好的狀態：該講的都講了，能查的都查過了。
