# G1 窗口閘門報告：程式碼生成的窗口實測

> 直接量測，非文獻重建。40 題 LeetCodeDataset Medium/Hard × 8 個 Haiku 候選解，
> 318 個候選在沙箱中對隱藏測試套件評分。重現：`experiments/run_g1_window.py`。

## 判定：**未通過**（窗口 7.5% < 閘門 15%）

| 量 | 值 |
|---|---|
| 每候選通過率 pass@1 | 0.697 |
| 基線（最大行為叢集） | 30/40 = 0.750 |
| oracle（任一候選正確） | 33/40 = 0.825 |
| **窗口 = oracle − 基線** | **3/40 = 0.075**，CI95 (0.026, 0.199) |

對照：HumanEval+/MBPP+ 實測 3.56%；QA 計畫薄窗 2–5%；
審查者從 ACES 表格**重建**的 LeetCodeDataset 值 24–27%。
**我的直接量測（7.5%）遠低於重建值**，差異來源是候選預算：
重建假設 n≈200，我測 n=8。見下節。

## 題目形態：與 QA 計畫同構

| 形態 | 題數 | 說明 |
|---|---|---|
| 基線已正確（飽和） | 30 (75%) | 方法無事可做 |
| 無任何候選正確（能力牆） | 7 (18%) | 池中沒有正解，聚合無能為力 |
| **窗口（可救援）** | **3 (8%)** | 唯一能改變結果的分層 |

這正是 TACT 論文薄窗章節的結構：題目從「飽和」直接跳到「能力受限」，
中間帶很薄。**在程式碼生成上重現了同一個形狀。**

## 窗口對候選預算 N 的依賴

用每題實測通過率外推 `oracle@N = 1−(1−p)^N`：

| N | oracle | 基線 | 窗口 |
|---|---|---|---|
| 4 | 0.789 | 0.750 | 0.039 |
| 8 | 0.808 | 0.750 | 0.058 |
| 16 | 0.820 | 0.750 | 0.070 |
| 32 | 0.824 | 0.750 | 0.074 |
| 128 | 0.825 | 0.750 | **0.075（飽和）** |

基線固定於 N=8 的值，因為最大叢集在更多抽樣下只會更銳利地收斂到**眾數行為**
——眾數是否正確正是 `baseline_correct` 已經量到的事。

**結論：增加 N 唯一可能的幫助，是救回那 7 個能力牆題目**（若其真實通過率
小而非零）。8 次抽樣無法分辨 p=0 與 p=0.05。該實驗（每題 +32 候選）進行中，
是本閘門的最後一塊；結果將決定 G1 是確定性失敗，還是在 n≈100 下可能通過。

## 附帶的方法學結果（獨立於 KAPPA-P）

沙箱 harness 以基準自身驗證：180 題參考解 **178 題通過**（2 題因逾時排除，
避免壞標籤污染）。任何用執行來評分的研究都應先報告這個數字——它區分
「候選錯」與「harness 錯」，而本次第一版 harness 因 macOS 拒絕 `RLIMIT_AS`
而 100% 誤判為失敗，若未做此驗證就會得到完全錯誤的結論。

## 最終判定（深挖後）：**確定性失敗**

7 個能力牆題目各追加 32 個候選（224 個），**零個正確**。
每題合併 40 次抽樣後通過率的 95% Wilson 上界為 **0.088**——
這些是真正的能力極限，不是抽樣運氣。

| | 窗口 |
|---|---|
| n=8 | 3/40 = 0.075 |
| n=40（深挖後） | 3/40 = **0.075**（未變） |
| 閘門 | 0.150 |

**提高候選預算無法打開這個窗口。** 基質被拒，KAPPA-P 不實作。

## 這個結果的更大意義：薄窗是跨領域的

薄窗現象原本只在無標籤 QA 上量到（三個基質，2–5%）。本實驗把它
延伸到**外部真值便宜**的程式碼生成領域：

| 領域 | 基質 | 窗口 |
|---|---|---|
| QA（無標籤） | GSM8K/CSQA、MATH-L5、AIME/AMC | 2–5% |
| 程式碼（有可執行真值） | HumanEval+/MBPP+（公開表格） | 3.56% |
| 程式碼（有可執行真值） | **LeetCode Medium/Hard（本實驗直接量測）** | **7.5%** |

「外部真值便宜的地方窗口更寬」這個假設——整個下一個計畫的前提——
**被自己的實驗推翻**。程式碼生成的窗口比 QA 稍寬（7.5% vs 2–5%），
但仍遠低於任何方法能在合理題數上證明自己的門檻，且形態完全同構：
75% 飽和、18% 能力牆、8% 可救援。
