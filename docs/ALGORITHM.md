# RLEV-VoI 演算法設計與數學推導

> 英文完整規格（含新穎性定位、證偽條件、紅隊修正紀錄）見 [SPEC.md](SPEC.md)。
> 本文是中文版的設計動機與數學推導。

## 1. 問題設定

給定凍結的 LLM 與問題 `q`，可以取樣 K 條思維鏈 `r_1..r_K ~ p(·|q)`，每條產生離散答案 `a_k`。目標：**在給定 token 預算下最大化答對率**。

基準線 Self-Consistency（Wang et al. 2022）：

```
â_SC = argmax_a Σ_k 1[a_k = a]
```

### 兩個結構性缺陷

**缺陷一：SC 假設票票獨立，但取樣鏈是相關的。**

多數決的統計正當性建立在「每票攜帶獨立資訊」上。但同一個 LLM 在同一題上取樣，很容易反覆走上同一條推理模板。如果那個模板是錯的，它會靠**複製自己**贏得多數決——錯誤被重複計數，而不是被獨立驗證。

**缺陷二：固定 K 對每題一視同仁。**

簡單題三票就穩定，難題三十票還在搖擺。固定 K 同時做到「浪費」和「不足」。

## 2. DDWC：冗餘折扣加權共識

### 2.1 從有效樣本數出發

這其實是複雜抽樣統計的老問題：**相關樣本的實際資訊量小於名目樣本數**。Rao–Scott（1981, 1984）的設計效應修正就是在處理這件事——把名目計數 `n` 換成有效計數 `n_eff = n / DEFF`。

設相似度核 `S`，`S_ij ∈ [0,1]`，`S_ii = 1`。定義：

```
s_i = Σ_j S_ij          相似度質量
w_i = 1 / s_i           有效權重
```

直覺：`s_i` 是「有多少條鏈跟我很像」（含自己）。周圍越擁擠，我的邊際資訊越少，權重越低。

### 2.2 區塊模型下的閉式解（正確性的支柱）

設軌跡分成若干群組 `g`，群內兩兩相似度都是 `ρ_g`，跨群為 0，群大小 `m_g`。則群內任一條鏈：

```
s_i = 1 + (m_g − 1)ρ_g
```

該群的有效票數：

```
N_g^eff = m_g · w_i = m_g / (1 + (m_g − 1)ρ_g)
```

兩個極限正是我要的行為：

| 極限 | 結果 | 意義 |
|---|---|---|
| `ρ_g → 1` | `N_g^eff → 1` | 完全回音 ⇒ **只算一票** |
| `ρ_g → 0` | `N_g^eff → m_g` | 真正獨立 ⇒ 全額計票 |

### 2.3 為什麼不能用 Kish 比值（關鍵修正）

有效樣本數在文獻上常寫成 Kish 比值：

```
n_eff^Kish = (Σ_i w_i)² / Σ_i w_i²
```

**這在本問題上是錯的。** Kish 比值量的是**權重的離散程度**，不是獨立票數。考慮 K 條完全相同的複本：所有 `w_i = 1/K`（均勻），代入得

```
n_eff^Kish = (K · 1/K)² / (K · 1/K²) = 1 / (1/K) = K
```

K 條逐字複製，Kish 說有 **K 票獨立資訊**——恰好相反。

正確的有效計數是**權重和**：

```
n_eff = Σ_i w_i = tr(D⁻¹S),   D = diag(s_i)
N_a^eff = Σ_{i: a_i = a} w_i
```

同樣代入 K 條複本：`n_eff = K · (1/K) = 1` ✓

這個錯誤由紅隊審查抓出，並固化成單元測試 T2/T3（見 `tests/test_units.py`）。Kish 比值在程式碼中僅保留為診斷指標，絕不進入後驗。

### 2.4 相似度—正確性混淆，與雙通道分解

**這是本方法最大的風險。** 在數學、程式這類題目上，正確答案往往就是**唯一一條標準推導**——所有答對的鏈彼此高度相似。天真地用相似度打折，等於專門懲罰正確答案。

解法是把冗餘拆成兩個性質完全不同的通道：

| 通道 | 訊號 | 與正確性的關係 | 折扣力度 |
|---|---|---|---|
| `dup_ij` | 字面近乎逐字重複（n-gram Jaccard） | **無關**——逐字複製不管對錯都是冗餘 | 重（安全） |
| `sem_ij` | 語意相似（嵌入餘弦） | **混淆**——正確答案常有標準推導 | 輕（`β_sem`） |

用 hinge-power 轉換讓門檻很陡，只有極高相似度才算數：

```
φ_{θ,γ}(x) = ((x − θ)₊ / (1 − θ))^γ

S̃_ij = φ_{θ_dup,γ_dup}(dup_ij) + β_sem · φ_{θ_sem,γ_sem}(sem_ij)
S_ij  = ρ · clip_{[0,1]}(S̃_ij)     (i ≠ j),      S_ii = 1
```

凍結預設：`θ_dup=0.9, γ_dup=6`（只塌陷近乎逐字者）、`θ_sem=0.6, γ_sem=3, β_sem=0.25`（語意只能輕推，不能主導）、`ρ=0.7`。

**`ρ = 0 ⇒ S = I ⇒ w_i = 1 ⇒ 精確退化成 Self-Consistency。**

### 2.5 never-worse-than-SC 護欄

即使有雙通道分解，仍需要一道硬保險。只有在**多數決本身是逐字回音叢集**時，才允許 DDWC 推翻它：

```
ESSratio_dup(a) = (Σ_{i∈G_a} w_i^dup) / n_a
```

其中 `w_i^dup` 只在答案類別 `G_a` 內、只用 dup 通道計算。對 m 條互為逐字複製者：

```
ESSratio_dup = 1 / (1 + (m−1)ρ)
```

（spec 標題寫的 `1/m` 只在 `ρ→1` 極限成立；實作依 pseudocode 帶 `ρ` 因子。在凍結預設 `ρ=0.7, η_dup=0.5` 下，護欄在 **m ≥ 3** 條逐字複製時解除保險。）

輸出規則：

```
â = â_DDWC   若 â_DDWC ≠ â_SC  且  ESSratio_dup(â_SC) ≤ η_dup  且  W_{â_DDWC} ≥ (1+δ)·W_{â_SC}
    â_SC     其他情況
```

三個條件全中才推翻，否則 SC 答案照舊。`δ, η_dup` **在所有 regime 與資料集上凍結**，不得逐一調參——否則「never worse」就變成可以事後湊出來的空話。

## 3. VoI-Stop：自適應停止

### 3.1 設計效應修正後的後驗

```
α_a = α₀ + N_a^eff,        θ | data ~ Dir(α)
```

**後驗只吃冗餘通道，不吃信心通道。** 這件事很重要：

- `S = I` 時 `w_i = 1`、`N_a^eff = n_a`，於是 `α_a = α₀ + n_a`——**無條件精確退化成 Adaptive-Consistency**。若後驗也吃信心，這個歸約只在 `g(c)=1` 時成立。
- 信心只作用在共識的 argmax：`W_a = Σ_{i:a_i=a} w_i · g(c_i)`。

誠實的表述：我只主張**偽計數增量 `α_a − α₀ = N_a^eff` 是有效計數**。後驗平均值 `E[θ_a] = (α₀+N_a^eff)/(α₀|𝒜|+n_eff)` 會被 `α₀` 往均勻收縮，並不等於 `p_a^eff`。

### 3.2 領先穩定機率

`|𝒜| = 2` 有精確解。`θ_ℓ ~ Beta(α_ℓ, α_R)`：

```
P_stable = Pr[θ_ℓ > 1/2] = 1 − I_{1/2}(α_ℓ, α_R) = I_{1/2}(α_R, α_ℓ)
```

`|𝒜| > 2` 沒有閉式，用蒙地卡羅估計**眾數機率** `Pr[argmax_a θ_a = ℓ]`。

> **實作改良（相對 spec）**：spec 寫每步重抽 Dirichlet。但 B=512 在 p≈0.95 附近的標準誤約 1e-2，跟到門檻 `τ=0.95` 的距離同一個量級——停止時間會因為與證據無關的 MC 噪音而抖動。
>
> 本實作改用**共同亂數 + 逆 CDF 取樣**：固定一組均勻亂數 `U`，每個 Dirichlet 樣本由 `θ_a ∝ Gamma⁻¹(α_a, U[b,a])`（`scipy.special.gammaincinv`）建構。這讓 `P_stable` 成為 `α` 的**確定性平滑函數**，相鄰步驟在完全相同的隨機性下比較。估計量對眾數機率仍無偏，只是消除了步間噪音。

注意：`|𝒜| > 2` 時的成對 Beta 檢定 `Pr[θ_ℓ > θ_R]` **不等於**眾數機率（領先者可以在 `θ_ℓ < 1/2` 時仍是眾數），只能當快篩，不能當主要指標。

### 3.3 資訊價值

```
π_a = α_a / Σ_b α_b                    後驗預測
w̄  = n_eff / K                        下一條鏈的期望權重
VoI = E_{a~π}[ P_stable^{+a} ] − P_stable
```

`w̄` 用**實際平均權重**而非 1：新抽的鏈預期跟已有的一樣冗餘。

> **誠實警告**：因為每個假想投票後都重新計算領先者，這個量幾乎必然非負，**不是** Howard (1966) 的精確 EVSI／貝氏風險下降量。本實作只把它當作**相對邊際遞減訊號**，並 clamp 在 0，不主張任何決策論最適性。

### 3.4 兩種停止規則

同時維護原始後驗 `α^raw = α₀ + n_a`（＝ ASC）與有效後驗 `α^eff = α₀ + N_a^eff`：

- **SAFE**：`min(P^raw, P^eff) ≥ τ`
- **AGGRESSIVE**：`P^eff ≥ τ`

**必須誠實說清楚的架構事實**：因為 `min(P^raw,P^eff) ≤ P^raw`，SAFE **永遠不可能比 ASC 更早停**。它是拿 token 換準確率／安全性，**在 token 面上不可能贏過 ASC**。任何 token 節省只能來自 AGGRESSIVE（且只在**對手**才是冗餘叢集時有效）或 VoI 分支。

## 4. 複雜度

| 項目 | 成本 |
|---|---|
| LLM 呼叫 | K 次生成，**不需要額外呼叫** |
| 嵌入 | K 次（本地編碼器） |
| 相似度 | 每步 O(K)，總計 O(K²) |
| `P_stable` | MC O(B·\|𝒜\|)／每步 |
| VoI | O(\|𝒜\|) 次 `P_stable`／每步 |

成本 x 軸一律用**總 token 等價量**（生成 + 嵌入 + 相似度 + 後驗），在**匹配預算**下比較，絕不用匹配 K；且對所有用到嵌入／相似度的方法收取相同的 `o_n`。

## 5. 何處有保證、何處沒有

**精確成立**：`S=I ⇒` 精確 ASC；`ρ=0 ⇒` 精確 SC；區塊模型「一叢集一票」極限；SAFE 不可能早於 ASC 停止。

**近似**：把 `N_a^eff` 當成 `n_eff` 次獨立類別抽樣是動差／ESS 匹配（Rao–Scott 精神），不是相關投票的精確概似。

**沒有保證**：固定 `τ` 的選擇性停止會膨脹型一錯誤——**不主張 anytime 有效性**。
