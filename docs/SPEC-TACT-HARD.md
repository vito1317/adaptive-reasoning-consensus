# SPEC：TACT 在非飽和基質上的確認實驗（預註冊）

> 寫於資料收集**之前**（2026-07-31）。30 題探測（`results/math_probe_raw.json`）
> 只用於選擇基質，探測過的 15 個 level-5 題目**排除**在確認集之外。

## 動機

GSM8K/CSQA 真實實驗結構性無訊息：多數決 91/100 正確，決定性分層 n=9，
D̂ = −0.219 (z=−1.24) 檢定力不足。探測顯示 MATH-500 level 5 對 Haiku：
多數決正確率 0.40、決定性分層 60%、混合池內信心-正確性相關 +0.59、
gold-in-pool 0.60。此外每樣本正確率 < 1/2，**命題 4 的前提（ρ̄ < 1/2）在此
真實地被違反**——TACT 論文新增的限制章節預測 TACT-LF 會判錯符號，
semi-LF 應為預設。本實驗同時檢驗方法與該限制的真實性。

## 設計

- **確認集**：MATH-500 level 5 排除探測題後的 119 題。
- **採樣**：每題 K=16 條獨立 Haiku 軌跡（答案 + 信心 ∈ [0,1]），批次 ≤15 題
  避免輸出上限。
- **分桶**：`math_grade.canon`；**評分**：`math_grade.equivalent`（sympy 等價）。
- **符號集**：從確認集隨機抽 30 題（seed=20260731）當 semi-LF 的符號估計集
  （只用 gold 決定 D̂ 的符號與 γ 封頂）；**評估集 = 其餘 89 題**。

## 方法（全部在同一批軌跡上）

| 方法 | 說明 |
|---|---|
| SC | 多數決（canon 分桶） |
| dedup-SC | 答案等價類去重加權多數決（此基質上預期 ≈ SC，仍必列） |
| best-conf | 取單一最高信心樣本的答案（**平凡基線**：若它追平 TACT，加權機制是裝飾） |
| CISC-式 | 信心線性加權投票（無 tempering） |
| TACT-LF | 全無標籤（預期在 ρ̄>1/2 **判錯符號**——此為限制章節的確認測試） |
| TACT-semi-LF | 符號來自 30 題符號集，其餘無標籤 |
| oracle-in-pool | 池中含 gold 即計對（**天花板**，非方法） |

## 預註冊證偽器

- **H1（通道存在）**：評估集上 pooled D̂ > 0 且 z ≥ 2（vdW + van Elteren，
  以 gold 計算）。失敗 → TACT 在此也無通道，記錄 null，停止。
- **H2（主終點）**：TACT-semi-LF 在**決定性分層**（SC 錯的評估題）上
  net corrections > 0 且 McNemar 精確單尾 p < 0.05（相對 SC）。
- **H3（基線防線）**：TACT-semi-LF 整體準確率 ≥ SC、≥ dedup-SC，且
  **> best-conf**。若 best-conf ≥ TACT-semi-LF：加權機制無增量，如實記錄
  （這不可豁免——本專案已有兩個方法死於缺席的平凡基線）。
- **H4（限制確認）**：TACT-LF 的 γ 符號在此基質為負（判錯方向）或四警報
  有觸發；若 TACT-LF 居然**贏過** semi-LF，論文的限制章節錯誤，需修正。
- **H5（誠實報告）**：per-sample 準確率、ρ̄ 估計、決定性分層大小、
  gold-in-pool 率全部進報告；評估集上任何事後子集選擇都標記為探索性。

## 成功與失敗的公開標準

- H1+H2+H3 全過 → TACT 的真實資料證據成立，寫進論文替換「僅合成」限制。
- H1 過、H2/H3 敗 → 通道存在但機器不行，記錄；TACT 降級為合成階段結果。
- H1 敗 → 兩個基質上通道皆不存在，TACT 的實用主張撤回，只保留理論。
