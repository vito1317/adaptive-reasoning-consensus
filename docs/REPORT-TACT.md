# 實驗報告：TACT（信心穩健加權）

> **結論先講：這次是正面結果，且四項預先登記的證偽條件全數存活。** TACT 用一條解析管線（排名統計量 → 收縮 → 判別連結）取代 CISC 的固定信心指數，其中**無標籤變體在完全沒有標籤的情況下辨識出信心通道的正負號與強度**——這是所有已發表方法（CISC、ReASC、DeepConf、各種加權 SC）都做不到的事：它們只會正向加權，負相關的信心一律中毒。
>
> 誠實的邊界同樣量化了：中段 κ 的收縮成本（相對 dev 符號網格 −0.005 ~ −0.015）、異質通道的全域地板、以及自信回音下無標籤保證的條件性（由警報退回 SC，需 ~50 個標籤解鎖）。

數據：`results/tact_eval.json`（每格 400 題、K=15、配對池、McNemar）。上游問題陳述：`results/kappa_sweep.json`。規格：[SPEC-TACT.md](SPEC-TACT.md)。

---

## 1. 方法一句話

投票權重 `w_i = exp(γ·φ_i)`，`φ_i` 是題內信心中位秩的標準化 van der Waerden 分數（對一切嚴格單調失真免疫）；`γ` 不是網格搜尋來的，而是由**混合 van Elteren Somers' D**（= 2·WQD−1，帶精確 tie 校正零假設變異數與逐題 jackknife SE）經**正部 James–Stein 收縮**（無證據 ⇒ γ=0 ⇒ **位元級等同 SC**）與**混合變異數校正的 Bayes 判別連結**推導出來。

三種餵法：**TACT-dev**（200 個標籤）、**TACT-LF**（零標籤：dedup 加權多數決偽標籤 + margin 閘門 + CCN 衰減理論 + split-half 去衰減 + 回音警報）、**TACT-semi**（~50 個標籤只取符號，強度來自無標籤流量）。

## 2. 主結果

三個讀點：

1. **已發表的協定在整個負半軸貼死 SC 地板**（CISC-devT 只有正向網格；ECE 閘門永遠關閉）。TACT 在 κ=−0.6 拿滿分——負相關的信心翻轉後就是滿分訊號，但你得先有「符號」這個概念。
2. **TACT-LF 與 TACT-dev 幾乎逐點重合**——零標籤達到有 200 標籤的水準，包括負號辨識（`d_raw=−0.81, z=−17.6`，一致性代理在多數決通常正確時是符號一致的，正如 CCN 定理預測）。
3. κ=0 時 γ 精確為 0：死區把「不劣於 SC」變成「就是 SC」，統計檢定無從拒絕。

### 2.2 對抗情境

| 情境 | SC | CISC-devT | 符號網格 | **TACT-dev** | **TACT-LF** | oracle(原始值家族) |
|---|---|---|---|---|---|---|
| 單調壓扁 | 0.795 | 0.965 | 0.965 | **1.000** | **1.000** | 0.965 |
| 單調過度自信 | 0.795 | 1.000 | 1.000 | 1.000 | 1.000 | 1.000 |
| 單調冪次 | 0.795 | 1.000 | 1.000 | 1.000 | 1.000 | 1.000 |
| 異質 κ | 0.810 | 0.810 | 0.810 | 0.810 | 0.810 | 0.810 |
| 自信回音 | 0.200 | 0.200 | 0.550 | **0.585** | 0.200（警報→SC） | 0.550 |

- **單調壓扁是排名不變性的乾淨勝利**：信心被壓到 0.5 附近時 `c^γ` 權重近乎均勻，整個原始值權重家族（含其 oracle 0.965）都被 TACT 的 1.000 超越。這正是 kappa_sweep 基線實驗預先量到的 headroom，如期收割。
- **自信回音**：TACT-dev 用標籤看穿「高信心=錯」（γ=−1.20），0.585 是全場最高（SC 的三倍）；TACT-LF 的 E1 警報正確拒絕並退回 SC——**條件保證按設計運作**，不假裝無標籤能解決理論上不可解的符號歧義（Parisi/Hui–Walter）。
- **異質 κ**：所有全域方法貼地板，包括 TACT（z=0.93 → 死區 → SC）。這是 §4.7 明說的範圍限制。

### 2.3 小 dev set（n=50）

結論不變：TACT-dev 在 ±0.6 仍拿 1.000，−0.2 仍 0.978。收縮的 SE 感知讓小樣本下的行為平滑退化而非崩潰。

## 4. 誠實的帳單

1. **對符號網格的淨勝利很窄**：同質掃描上 TACT ≈ 符號網格（中段甚至小輸 0.005–0.015，收縮的保守代價）。TACT 超出平凡基線的部分只有：(a) 排名不變性（壓扁 +0.035、回音 +0.035）、(b) **無標籤運作**（符號網格需要標籤，這是 LF 的獨有能力）、(c) 解析推導無需網格。若部署場景有充足標籤且信心尺度可靠，符號網格就夠了——這句話寫進結論。
2. **LF 的符號保證是條件的**（多數決錯誤率 < 1/2 且無自信回音）；警報只防得住逐字回音（E1 走 dup 通道），改寫式回音會逃過——semi-LF 用 50 個標籤補洞，是誠實的建議部署。
3. **異質通道是真空白**：全域 γ 在數學上就贏不了（上游實驗已證 oracle 全域=SC 地板）。TACT-hier 的兩層收縮列為未來消融。
4. E2 警報的第一版是**符號天真**的，在良性負相關通道上全部誤觸發——LF 曾因此在整個負半軸失明。修正為符號感知版本後才有 2.1 的結果；此缺陷與修法記錄在 commit 歷史。
5. 合成資料的耦合模型正是估計器所測的量——**循環性風險**由三點緩解：對抗情境（失真/異質/回音）不在估計器的模型內、機制檢查與準確率主張分開報告、以及真實 LLM 軌跡的驗證（`run_real_api.py` 可直接沿用，需 API key）留作最終檢驗。

## 5. 與上一個專案（RLEV-VoI）的關係

RLEV-VoI 的負面結果指出：CISC 類方法的效益被「校準崩壞就毀滅」綁架，而二元 ECE 閘門把嬰兒和洗澡水一起倒掉。TACT 就是對那個兩難的正面回答——連續、有符號、可無標籤。兩份報告合起來是一個完整的研究弧線：先誠實殺掉一個不值得活的想法，再從它的屍檢報告裡找到值得做的下一個。

## 6. 後續研究：異質性的正反兩面（TACT-group 與逐題不可能性）

第 2.2 節留下的空白——異質 κ 情境所有方法貼死 SC 地板——後續研究給出了完整的答案：一個不可能性結果加一個可行的方法。數據：`results/group_eval.json`（600 題/格）。

### 6.1 逐題自適應在 i.i.d. 異質下是不可能的

三個互相印證的證據（皆固化為測試）：

1. **自我增強恆等式**：任何把「題目自身的一致性統計量」單調映到指數的方法都只會增強多數決——`D^g>0 ⇒ γ>0 ⇒` 加權自信票（多數方）；`D^g<0 ⇒ γ<0 ⇒` 加權低信票（也是多數方）。實測與 SC 一致率 97.5%，僅有的翻轉淨傷害（翻對 1 翻錯 9）。
2. **贏家詛咒**：在多數決錯誤（唯一可贏）的題目上，一致性統計量的符號與真實符號 **96% 相反**——訊號恰好在最需要的地方指向反方向。
3. **兩世界不可辨識**：`{κ>0, 少數方正確}` 與 `{κ<0, 多數方正確}` 產生完全相同的可觀測 `(answers, confidences)` 聯合分布（`D^{w1} = −D^{w2}` 精確成立）。任何無標籤方法原則上無法區分。

結論：i.i.d. 潛在 κ 下，逐題 oracle（0.983）對一切合法方法不可達。實驗中所有 TACT 變體在此格**精確**退回 SC（配對不一致數 +0/−0——死區的位元級退化按設計運作）。

### 6.2 結構化異質性是可解的：TACT-group

真實語料的異質性沿**可觀測協變量**結構化（領域、題型）。把 κ 改為由群組標籤索引（三群：+0.6 / 0 / −0.6），按群跑既有的 TACT 機制：

| 方法 | 準確率 | vs SC |
|---|---|---|
| SC 地板 / 全域 TACT | 0.808 | — |
| TACT-group-dev | 0.923 | p=1.9e-14（+79/−10） |
| **TACT-group-LF（零標籤）** | **0.940** | p=3.3e-24（**+79/−0，零敗**） |
| 逐題 link oracle（上限） | 0.947 | — |

- 兩種變體都完美恢復各群的符號結構（dev: {+4.0, 0.01, −4.0}；LF: {+2.0, 0.0, −2.0}），κ=0 的群正確落入死區。
- **零標籤的 TACT-group-LF 距離逐題 oracle 只差 0.007**，且對 SC 一題未輸。
- 有趣的觀察（如實報告，非事後調參）：LF 在此格勝過 dev（0.940 vs 0.923），原因是 LF 的較低指數上限（±2 vs ±4）避免了單一自信票的過度集中——dev 變體在 |D|≈1 的群組推到上限後近乎「argmax 信心」。上限選擇的穩健性列為待做消融。
- 小群組（< 30 題）自動退回全域估計——由 6.1 的不可能性，這不是折衷而是唯一站得住的行為。

### 6.3 修訂後的範圍聲明

TACT 的完整能力邊界現在是閉合的：**全域通道 → TACT-dev/LF；沿可觀測協變量結構化的異質 → TACT-group（可零標籤）；i.i.d. 逐題異質 → 資訊論封閉，正確行為是退回 SC，且 TACT 的死區保證它精確做到這件事。**
