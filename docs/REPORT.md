# 實驗報告：RLEV-VoI

> **結論先講：這是一份負面結果報告。** 演算法診斷的問題是真的、而且很嚴重（在逐字回音情境下 Self-Consistency 從 0.320 掉到近乎隨機），提出的機制也確實有效（RLEV-VoI 把它拉到 0.880，p≈7e-68）。但一個**簡單得多的基準線**——單純的近重複去重 + 信心加權 + 穩定度停止（RASC-lite）——在**每一個**情境都以明顯差距勝過它。
>
> 按照 [SPEC.md](SPEC.md) §8.b 預先登記的證偽條件，本方法至少觸發三項「no-paper condition」。以下逐項報告。

所有資料來自 `results/frontier.json`（5 情境 × 400 題 × 660 配置）與 `results/boundary.json`。重現指令見 [README](../README.md)。

---

## 0. 這些實驗能證明什麼

合成資料的生成過程**正好就是** DDWC 假設的區塊叢集結構。因此：

- **可以**證明：實作正確性、歸約關係、消融歸因、無退步性、適用邊界。
- **不能**證明：在真實 LLM 軌跡上有效。R2/R4 的增益是資料生成方式的產物。

真正的 headline 證據需要 API key，腳本已備妥（`experiments/run_real_api.py`），本次未執行。

## 1. 實作正確性：48 項測試全數通過

強制單元測試 T1–T6（`tests/test_units.py`）以**解析極限**驗證估計量，不依賴模擬結果：

| 測試 | 驗證內容 | 結果 |
|---|---|---|
| T1 | `S=I` ⇒ `w_i=1`、`N_a^eff=n_a`，且整條管線與 ASC 的答案**與停止時間**逐項相同 | ✅ 30/30 試驗，其中 ≥25 次真的提早停止（非空洞比較） |
| T2 | 全 1 矩陣（K 份複本）⇒ `n_eff = 1` | ✅ |
| T3 | 兩個完全相關等大區塊 ⇒ `n_eff = 2` | ✅ |
| T4 | `N_g^eff = m/(1+(m−1)ρ)` 閉式與兩端極限 | ✅ |
| T5 | m 條逐字複本 ⇒ 護欄觸發並推翻多數決 | ✅ |
| T6 | `ρ=0` ⇒ 精確等同 Self-Consistency | ✅ |
| 反向測試 | **Kish 比值必須在 T2/T3 失敗** | ✅ 回傳 K 與 12，而非 1 與 2 |

最後一項是刻意的：它讓被否決的錯誤估計量無法被悄悄改回去。

## 2. 開發過程中發現並修正的缺陷

對抗式審查（5 個審查面向 + 獨立驗證者）提出 30 項候選、確認 11 項。以下是**會影響已報告數字**的缺陷：

### 2.1 `P_stable` 估計量不具置換不變性（嚴重）

我用「Dirichlet 可交換」為由，把眾數機率估計值快取在**排序後**的 α 上。這對**精確值**成立，但對我的共同亂數估計量不成立——`gammaincinv` 把第 j 格綁到固定均勻矩陣的第 j 欄，置換 α 就換了每格抽到的亂數。

實測偏差最大 **0.1035**——相對於 τ=0.95 的門檻是巨大的，且意味著 `P_stable` 取決於答案的**任意整數編號**。

更糟的是：我為此寫的置換不變性測試**每次都命中快取**，回傳同一個值——測試在驗證快取，不是驗證估計量。

**修正**：估計量內部改用正規化排序，使其真正成為多重集的函數。測試改為直接呼叫 `_compute` 繞過快取。

### 2.2 VoI 比較兩個不同的支撐集（嚴重）

baseline 在 k 格上計算，但每個候選都被加上一個 `alpha0` 幽靈格變成 k+1 格。多一個競爭格必然降低眾數機率，所以 VoI 被系統性低估、單向推向提早停止——正是消融 (g) 要測量的量。

**修正**：baseline 與候選共用同一支撐集。

### 2.3 模擬器的回音群組不是團塊（嚴重）

`is_echo_of` 是一片森林，但程式只沿**祖先鏈**建立群組。兩條互為兄弟的逐字複本從未被標記為重複，`dup` 停在 ~0.5（遠低於 `θ_dup=0.9`）。組內只有 **31.5%** 的配對超過門檻，系統性地讓護欄在**專門測試它的情境**中失去武裝。

**修正**：改用 root 分組，使每個回音連通分量成為團塊。修正後 echo=0.8 的增益從 +0.333 升到 **+0.447**，護欄觸發率從 35% 升到 46%。

### 2.4 成本核算是全有全無（重要）

`uses_similarity` 是布林值，導致只用字面 n-gram 的 dedup-SC 和 RASC-lite 被收取它們從未計算的**嵌入**與**第二個相似度通道**的費用（約 2.15 倍的不實成本）。

**修正**：改成逐通道計費，嵌入與後驗/VoI 的蒙地卡羅計算分開定價。**注意方向**：修正前是**高估**競爭者的成本，也就是說修正後 RASC-lite 的優勢只會更大——這個缺陷從未對本報告的結論有利。

### 2.5 消融 (f) 量不到東西

`disable_guard` 實作成「回傳純 SC 答案」，但 spec 消融 (f)「guard on/off」要的是**無護欄的 DDWC**。修正後拆成 `disable_guard`（f）與 `force_sc_consensus`（h）兩個獨立開關。

### 2.6 其他

- 真實 API 腳本用 `or p.accuracy` 把超出範圍的 `None` 轉成 0.0 的完美無退步——會隱藏真實退步。
- 軌跡快取鍵漏掉題目文字、模型與供應商，不同模型/資料集會靜默共用快取。

## 3. 主要發現

### 3.1 簡單的去重基準線全面勝出（觸發證偽條件）

各方法在共同預算區間的 frontier 平均準確率差（正值代表 RASC-lite 領先）：

| 情境 | RASC-lite − RLEV-VoI | 是否完全支配 |
|---|---|---|
| R1 獨立 | **+0.261** | 是 |
| R2 相關錯誤 | **+0.335** | 是 |
| R4 逐字回音 | **+0.349** | 是 |

看各方法的**峰值準確率與達成成本**更刺眼——RASC-lite 通常同時更準且更便宜：

| 情境 | RASC-lite 峰值 @ 成本 | RLEV-AGGR 峰值 @ 成本 |
|---|---|---|
| R1 | **1.000** @ 2,230 | 0.958 @ 9,376 |
| R2 | **0.970** @ 1,936 | 0.710 @ 4,657 |
| R4 | 0.915 @ **1,375** | 0.915 @ 7,064 |

R1 是更準且只花 **1/4** 成本；R4 是同樣準確度但只花 **1/5** 成本。

SPEC §8.b 證偽條件「在匹配總成本下 frontier 未能明確支配 RASC 與 ASC」→ **成立**。

而 RASC-lite 只做三件簡單的事：丟掉近重複的推理、用信心加權、後驗穩定就停。沒有反相似度權重、沒有設計效應修正、沒有 VoI。

### 3.2 單純去重就追平了整個核函數（Claim 2 被否證）

凍結預設 vs `dedup-SC`，在相近成本下配對比較（McNemar）：

| 情境 | RLEV-VoI | dedup-SC | 差 | p |
|---|---|---|---|---|
| R2 | 0.698 | 0.723 | −0.025 | 0.27（不顯著） |
| R4 | 0.880 | 0.858 | +0.022 | 0.28（不顯著） |

若不限成本，dedup-SC 的**峰值**更高：R2 為 0.922（RLEV 0.710）、R4 為 0.993（RLEV 0.915）。

SPEC 證偽條件「plain dedup matches DDWC ⇒ 分解無效」→ **成立**。雙通道核函數相對於一行去重程式碼，沒有可測量的優勢。

### 3.3 效益幾乎全部來自逐字重複，不是語意相似度

Boundary map 掃過 30 種語意設定（`sem_shared` × `tightness`），語意參數**確實**大幅改變了權重：

- `n_eff/K` 從 **0.842 變動到 0.359**——2.35 倍的變動
- 但準確率增益只從 **+0.040 變動到 +0.067**（標準差 0.0074）

固定語意參數、只掃逐字回音率：

| echo 率 | n_eff/K | 增益 vs SC | 護欄觸發率 |
|---|---|---|---|
| 0.0 | 0.677 | +0.000 | 0.00 |
| 0.2 | 0.675 | +0.000 | 0.00 |
| 0.4 | 0.657 | +0.060 | 0.06 |
| 0.6 | 0.610 | +0.293 | 0.29 |
| 0.8 | 0.581 | **+0.447** | 0.46 |

相關係數把主從關係講得很清楚：

| 驅動因子 | 與增益的相關 |
|---|---|
| 逐字回音率 | **+0.935** |
| 叢集緊密度（語意） | +0.619 |
| `n_eff/K`（權重折扣量） | −0.354 |

**誠實的表述**：語意通道**不是**完全無作用（與緊密度相關 +0.619），但它被重複通道壓過約一個數量級——語意參數全程只帶來 0.027 的增益變動，回音率則帶來 0.447。權重折扣的**量**本身幾乎不預測效益（相關僅 −0.354）；真正預測效益的是**護欄有沒有在逐字回音上觸發**。

### 3.4 相似度—正確性混淆確實咬人（R3 無退步性被違反）

R3 是「正確答案本身就是一條緊密的標準推導」的情境——Limitation 1 預言的風險。

凍結預設 0.970 vs SC 0.993：**差 −0.022，CI[−0.040, −0.007]，p = 0.0117（顯著）**。

SPEC 證偽條件「guarded DDWC 在任一格顯著低於 SC」→ **成立**。

消融把責任指得很清楚：

- 護欄觸發率 = **0.000**（R3 沒有逐字重複，護欄根本無從保護）
- `abl-h_DDWCcons_rawstop`（保留 DDWC 共識、改用原始計數停止）**比完整方法好 +0.047**

也就是說：**傷害來自有效計數的停止規則，不是共識規則**，而護欄在設計上就管不到停止。

### 3.5 護欄的代價大於效益

消融 (f)（無護欄的 DDWC）對照完整方法：

| 情境 | RLEV-AGGR − 無護欄 |
|---|---|
| R1 | +0.002 |
| R2 | **−0.164** |
| R4 | **−0.024** |
| R5 | **−0.068** |

護欄在三個情境**主動阻止了正確的推翻**，而在它被設計來保護的 R3 從未觸發（觸發率 0.000）。在這個測試環境裡，護欄是淨負貢獻。

### 3.6 VoI 分支的預設 λ 失準三個數量級

實測 VoI/token 分布 vs spec 預設 `λ=1e-3`：

| 情境 | 中位數 | p90 | 最大值 | `< λ` 的比例 |
|---|---|---|---|---|
| R1 | 7.9e-06 | 7.6e-05 | 5.1e-04 | **100%** |
| R2 | 5.1e-06 | 6.0e-05 | 3.8e-04 | **100%** |
| R3 | 1.5e-05 | 7.6e-05 | 4.6e-04 | **100%** |
| R4 | 2.3e-06 | 4.0e-05 | 3.2e-04 | **100%** |
| R5 | 1.3e-05 | 1.1e-04 | 5.3e-04 | **100%** |

**沒有任何一次觀測值超過預設 λ。** VoI 分支因此無條件觸發，實際執行的是「`P_eff ≥ τ_floor` 就停」——`τ_floor` 在做全部的工作。這正是紅隊在設計階段點名的疑慮，現在有了實證。

凍結預設的停止原因分布也證實了這點：R4 有 358/400 題是被 VoI 分支停掉的，僅 42 題由穩定度決定。

把 λ 校準到實際量級後（掃描 1e-8 到 1e-3），消融 (g)「VoI vs 單純耐心門檻」的結果是**混合的**：R1 +0.020、R3 +0.017（VoI 較好）；R2 −0.035、R4 −0.064（VoI 較差）。**沒有一致的優勢。**

### 3.7 凍結預設違反了它自己文件化的 SAFE 保證

SPEC §4.3 與 Limitation 4 把「SAFE 永不早於 ASC 停止」列為**精確保證**，理由是 `min(P_raw, P_eff) ≤ P_raw`。

但凍結預設同時設定 `stop_variant="SAFE"` 與 `voi_branch=True`，而兩個分支是**析取**的——分支 B 可以遠早於分支 A 觸發。

保證只在 `voi_branch=False` 時成立。這一點現在由兩個測試釘住：`test_safe_never_stops_earlier_than_asc_with_voi_off`（保證成立）與 `test_frozen_default_breaks_the_safe_guarantee`（出貨預設違反）。

### 3.8 ECE 閘門：混淆了校準度與辨別力，但在 R5 是唯一的救命繩

閘門在**全部五個情境**都關閉了信心通道，包括校準良好的對照組（R1 ECE=0.197）。R1 的信心訊號辨別力極強——CISC 靠它達到 1.000，而 SC 的峰值只有 0.958——卻因為系統性低估自信而被 ECE 判定不合格。**ECE 量的是校準度，不是辨別力**：一個訊號可以完美區分對錯（AUC=1）卻校準很差，閘門會把它整個丟掉。

但 R5（信心與正確性反相關）證明了閘門的價值，而且這是**唯一一個 RLEV-VoI 表現最好的情境**：

| 方法 | R5 峰值準確率 |
|---|---|
| **RLEV-AGGR** | **0.728** |
| ASC | 0.725 |
| SC / dedup-SC | 0.720 |
| CISC | 0.412 |
| RASC-lite | **0.062** |

無條件使用信心的兩個方法（CISC、RASC-lite）徹底崩潰；RLEV-VoI 因閘門關閉信心通道而保住 0.690（凍結預設，對 RASC-lite 差 +0.672，p=2e-81）。

這是一個真實的取捨而非單純缺陷：閘門在校準良好時放棄一些效益，在校準崩壞時避免災難。代價是 R1 少了約 0.04；收益是 R5 沒有從 0.73 崩到 0.06。

### 3.9 自適應停止在低預算下可能被固定預算嚴格支配

R1 中 λ=1e-3（全部停在 K=5，平均 5.00）準確率 0.710；λ=3e-5（平均 5.43，**花更多算力**）準確率只有 0.652。

逐個停止點檢查顯示 RLEV 的準確率與 SC@同 K **完全相同**（0.690/0.690、0.548/0.548…），所以共識邏輯無誤。差異純粹來自**選擇效應**：VoI 決定繼續抽樣的題目，正是投票脆弱的難題（停在 n=5 的題準確率 0.690，被判定要繼續的只有 0.548）。多抽一兩條鏈救不回來，卻拉低了整體。

### 3.10 適用邊界

R1 的權重變異係數只有 **0.056**，剛好落在塌陷門檻（0.05）邊緣——在缺乏冗餘結構時，DDWC 在數學上與 SC 無法區分。這是良性的（不會變差），但也代表**零改進空間**。

實務意義：在真實資料上先算權重 CV，就能**事先判斷**這個方法有沒有機會幫上忙。

## 5. 什麼是站得住腳的

負面結果不代表一無所獲：

1. **問題診斷正確且重要。** 逐字回音讓 Self-Consistency 崩潰的程度是驚人的。R4 中在匹配成本下 SC 只有 0.320、ASC 只有 0.188（近乎隨機）。更關鍵的是**方向**：SC 在 R4 的峰值是 **K=1 時的 0.403**，多抽樣本反而**單調變差**——回音叢集會隨 K 增長吃掉多數決。這正是「票票獨立」假設失效的教科書案例，任何依賴多數決的推理系統都有這個弱點。

2. **修正後的估計量在數學上是對的。** `n_eff = Σw_i = tr(D⁻¹S)`，區塊極限「一叢集一票」由 T2–T4 解析驗證。被否決的 Kish 比值有反向測試釘住。

3. **有效的機制被精確定位了。** 不是反相似度加權、不是設計效應修正、不是 VoI——是**逐字重複偵測**。增益與回音率的相關高達 +0.935，與權重折扣量的相關只有 −0.354（3.3 節）。

4. **ECE 閘門的價值被獨立驗證。** R5 是唯一 RLEV-VoI 勝出的情境，而它勝出的原因是閘門在信心崩壞時關掉了信心通道——同場的 CISC 掉到 0.412、RASC-lite 掉到 0.062。這個安全設計值得保留，即使它不屬於原本主張的創新。

5. **事前可判斷性。** 權重 CV 是一個廉價的診斷指標，可在投入前判斷這類方法在特定資料集上有無空間。

6. **完整的證偽協定。** 每一項主張都有對應的證偽條件，而且**這些條件確實被觸發並如實報告**。

**實務建議**：如果你的推理系統受逐字回音之苦，先做最簡單的事——n-gram 近重複去重加信心加權。本研究找不到任何證據支持更複雜的做法。
