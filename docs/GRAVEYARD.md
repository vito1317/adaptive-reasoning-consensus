# 墓園：被殺掉的方向與死因

> 目的：防止重新發明。每個條目記錄設計、死因、與致命的引用或實驗。
> 新想法動工前先讀這份文件——本專案有兩個方法死於**同一個**缺席的基線。

## 1. RLEV-VoI（負面，實作後證偽）

信心加權 + VoI 自適應配額。**死因**：dedup-SC 在同預算下全面支配；
4.5/5 個預註冊證偽器觸發。詳見 [REPORT.md](REPORT.md)。

## 2. ISC — Instrumented Self-Consistency（負面，實作後證偽）

用驗證 prompt 當儀器錨定世界。**死因**：(a) 零儀器消融已達增益的 86%；
(b) dedup-SC 同預算 0.9600 vs 0.8925；(c) 模擬儀器是 oracle（156/156）；
(d) 真實自我驗證背書 87% 已知錯誤答案，δ=+0.115 vs 所需 0.60；
(e) **異模型驗證也失敗**——決定性分層 δ=−0.067，且與該模型直接解題 83% 一致
（是外包不是儀器）。詳見 [REPORT-ISC.md](REPORT-ISC.md)。

## 3. FIB — Frame-Invariance Bound（放棄，實作前）

用語意保持 frame 群的變異數下界錯誤率。定理為真（20 萬世界驗證零反例），
**但**：

- **被搶發**：Madani, Pennock & Flake, "Co-Validation", **NIPS 2004**, Eq. (4)
  ——代入 d=2v\* 後逐字相同，證明路徑相同（Var ≤ μ(1−μ)、解二次式取小根）。
- **被平凡界支配**：D = 1 − max_z E_g[π_g(z)]（1 減合併眾數佔比）無條件成立、
  不需 frame、處處 ≥ FIB，且 **D 是 sharp 的**——frame 保語意使 (π, y=y\*)
  永遠是一致世界，故任何有效無標籤下界 ≤ D。**此問題內沒有新界的空間。**
- 「繞過雙世界不可識別」是幻覺：frame-不變的錯誤使界歸零，恰在歧義咬人處。
- 反預測性：界的上限 min(μ\*, 1−μ\*) 隨模型變差而**下降**（AUROC 0.343）。
- 周邊搶發：FormInv (arXiv:2605.29001) Prop. 2；Valentin et al. AAAI 2026
  (arXiv:2507.00057) Thm 4.1（incoherence ≤ 2·error 的無 oracle 證書）；
  Nowak (arXiv:2509.19489) 的 m×n 估計理論；
  Chen–Rambachan–Tamer (arXiv:2606.15031) 的部分識別處理。

**教訓**：任何「無標籤界定錯誤率」的想法，先跟 1 − 眾數佔比比較。

## 4. RLSC mode-certification（放棄，實作前）

把 SC 當選舉、用 betting e-process 認證「領先者 = 母體眾數」，隨時可停。
**死因**：

- **被搶發兩次**：**MMC** — Cordero-Encinar & Duncan, "Certified
  Self-Consistency" (arXiv:2510.17472, 2025/10)：同一 estimand 轉換、同一
  e-process/Ville 構造、stop-on-certify、預算耗盡棄權。**CITE** — Ota et al.
  (arXiv:2605.05873, 2026/05)：逐字相同的 pairwise betting 構造 + 未知答案集
  處理 + minimax 下界 + 加權 W-CITE。ConSol (arXiv:2503.17587) 更早以 SPRT
  框架化。此角落 10 個月內兩篇獨立論文——**已飽和**。
- **lead rule 支配**（敵對審查，模擬證實）：一參數「領先差 ≥ c」規則在 iid 流
  上同時在兩軸支配 e-process 認證；δ=0.05 時省 53% 樣本、停 92% vs 36%。
- **路由不可能定理**：最終計票是充分統計量——e-deficit、margin、entropy 全是
  同一資訊的函數（AUC 0.699–0.753 無差異）。實測印證：真實資料上錯誤多數是
  **穩定的錯**（stable-wrong），9/9 決定性題照樣認證，router TP=0/FN=9。
- 「與 SC∞ 一致」沒有客戶：SC@40 免費就有 ~95% 一致率。
- 協定書寫層面：無對手時認證條件空洞成立（全票前綴 t=1 認證，9 倍 δ 違反）。

**教訓**：(a) 認證量測的是**穩定性**，與正確性在決定性分層上正交；
(b) 無標籤路由訊號不可能超越計票的充分統計量；(c) SC 效率/認證角落已飽和，
原創工作需換角落。

## 橫貫教訓（依發現順序）

1. **headline 基線必含 repo 內所有既有方法**——尤其 dedup-SC（殺了 #1、#2）。
2. **決定性分層協定**：只在多數決已錯的題目上評估——SC 之上的方法只能在此
   改變答案；整體指標被基準飽和度稀釋。三次獨立印證（見 REPORT-ISC.md §13）。
3. **平凡界檢查**：無標籤量的任何界，先跟眾數佔比類統計量比（殺了 #3）。
4. **審查先於實作**：FIB 與 RLSC 都在寫程式前被殺，各省一個實作週期。
   兩段式（五域文獻掃 + 多面向對抗攻擊 + 綜合判決）是本專案的標準閘門。
5. **穩定的錯**：真實模型的錯誤多數是自信且一致的——任何以「搖擺 = 可疑」
   為前提的訊號（含認證失敗、低 margin、高熵）在真實決定性分層上失明。
