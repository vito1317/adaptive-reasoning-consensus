[critical/math] The Kish ESS of the leverage weights, n_eff=(Σ_i w_i)²/Σ_i w_i², does NOT measure the number of independent votes — it measures weight *dispersion*, and returns K exactly when redundancy is uniform. Counterexample: all K traces identical ⇒ S is all-ones ⇒ s_i=K ⇒ w_i=1/K (uniform) ⇒ Σw=1, Σw²=1/K ⇒ n_eff=(1)²/(1/K)=K, NOT 1. Two equal fully-correlated blocks (ρ=1) likewise give uniform w ⇒ n_eff=K while the true effective count is 2. The spec's own block-model shows the coherent effective count is Σ_i w_i = tr(D⁻¹S) (=1 for all-ones, =2 for two blocks), yet the posterior α_a=α₀+n_eff·p_a plugs in the Kish ratio instead. So under correlated/echoed votes the 'design-effect-corrected' posterior injects up to K pseudo-counts — treating K identical copies as K independent votes — which is precisely the miscalibration Novelty 1 claims to fix. The spec never tests the uniform-correlation limit; it only checks the 'one dominating weight' case. This sinks Novelty 1.
   FIX: Use the coherent effective count n_eff := Σ_i w_i = tr(D⁻¹S) in the posterior, not the Kish dispersion ratio. WARNING: with g(c)=1 this makes n_eff·p_a = Σw·(W_a/ΣW) = W_a, i.e. it collapses back to the α₀+W_a form the spec declares 'wrong' — so the authors must either (a) justify α₀+W_a directly, or (b) prove a correlation-corrected count distinct from both Kish and the row-sum. Either way the current Kish choice is provably wrong and must be replaced, with the S→all-ones and equal-block cases added as mandatory unit tests.

[critical/experiment] The 'never-worse-than-SC' guard uses the same broken Kish statistic and therefore fails on the exact adversarial case it is designed for (Regime R4). [major/math] The top-2 leader-stability probability is mislabeled and can be badly biased for |𝒜|>2.
