# SPEC：KAPPA-P（重構後，預註冊；stop-gate 未過前不實作）

## 一句話主張

在**非飽和**的程式碼生成資料上，對候選叢集代表做 AST 突變得到的
per-(測試, 叢集) local kill rate κ_lj，可以在**分歧測試**上構成帶符號的
成對對比，其偏離多數決的方向富集於「多數決錯」的題目——而 κ 的第二個
索引（within-problem 的 per-cluster 可靠度）是文獻未claim的部分。

## 已驗證的結構性事實（作者獨立重現）

| 事實 | 驗證 |
|---|---|
| 可加式 per-cluster LLR = 正權重投票 + fragility 偏移 | 恆等式 2.31e-14；0/20000 反例 |
| 可加式版本可用突變體脆弱度買分數 | `score ~ +4.34·tally +13.66·mean_κ`, R²=0.984 |
| 成對版消除 confound | 行為相同候選精確打平 0/20000 |
| eps 是純尺度 | 恆等式 3.55e-14：`LLR = (n_AB−n_BA)·logit(1−eps) + K_κ` |
| eps→0 退化為均勻分歧投票（強制基線） | 代數確認 `Σ_B(n_AB−n_BA) = L·tally_A − const` |

## 已驗證的致命限制（作者用公開數字重現）

**飽和基準無法承載主終點。** 從 arXiv:2606.16999 Tbl 6 的 6 個
model×benchmark 格算出可尋址窗口（oracle − BoN）：

| 基準 | 窗口 |
|---|---|
| HumanEval+ / MBPP+ 合計 | **57/1602 = 3.56%** |
| QA 計畫的薄窗 | 2–5% |

**程式碼生成在飽和基準上的窗口與 QA 相同，不更寬。** 檢定力（capture
c=0.22，harm 0.5%）：HumanEval+ 0.001、MBPP+ 0.027、兩者合計 0.052
——N>4000 才有 80%，可得只有 542。**主終點在此類基準上不存在。**

## 未定案的爭點（雙方模擬都是漫畫模型）

審查者稱「不存在使偏離率落入窗口的 eps」（實測 9.7–27.6%）；
作者在自己的參數化下測得 4.5–11.4%，eps≈1e-3 時 Borda 為 4.5%，**落在窗口內**。
兩邊都用隨機 pass row，**需要真實執行叢集池才能定案**——這正是 stop-gate。

## 重構：唯一可能成立的區域

窗口在**難、非飽和**資料上才夠寬。審查者從 ACES 的 LeetCodeDataset 欄
重建得 24–27%（並有 +8/+11/+18 的顯著實現增益，p 至 <1e-4）——此為
**重建值，非原文直接報告，須自行量測確認**。檢定力：
LiveCodeBench v5 (N=880, w=7.5%) → 0.76；LeetCode 類 (N=228, w=24.5%) → 0.96。

## 強制 STOP-GATE（在任何實作之前）

**G0 — 富集閘門。** 在自行收集的快取池上量測

    E = P(題目在窗口內 | KAPPA-P 偏離多數決) / P(題目在窗口內)

規則同 Lemma 1（2606.16999）：偏離若對「多數決是否已正確」盲目，
期望淨值為負。**E < 2 → 設計在該基質上死亡，不實作。**
同時報告 d(eps) 在**真實**池上的曲線，取代兩份漫畫模擬。

**G1 — 窗口確認。** 自行量測所選基質的 oracle − BoN；若 < 15%，
換基質或停止。

## 若 G0/G1 通過才進行的預註冊證偽器

- F1 κ 代理效度：**within-cluster 中心化**殘差 (κ_lj − mean_j κ_lj) 對
  cluster-local 真 P(fail|incorrect) 的相關 > 0.5，且必須勝過零成本 null
  （「候選中有多少比例在測試 j 上失敗」——審查者證明該 null 相關達 0.998）
- F2 主終點：決定性分層上勝過 uniform-vote、**mutation-hardened suite +
  均勻投票（MIST-RL）**、ACES-C/O、B4、Dawid-Skene/EM，同執行預算
- F3 不傷害：整體準確率不低於最佳基線 0.5 分
- F4 排序規則：用 **Borda 而非 Copeland**（Copeland 有無訊號的結構性偏離floor）
- F5 誠實預算：L·K·M 次額外執行計入，基線給予等量的額外候選或測試
- F6 報告 b01/b10 不一致對計數，不報 Δpass@1
